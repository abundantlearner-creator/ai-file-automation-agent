# AI File Automation Agent

## Overview
This project is a Python-based automation tool designed to organize files and streamline workflow categorization. It routes files into structured folders based on predefined rules, reducing manual effort and improving efficiency.

## Features
- Automatically sorts files into categories such as School, Trading, Business, and Books/PDFs
- Applies rule-based logic to determine file placement
- Helps maintain a clean and organized file system
- Reduces time spent on manual file management

## Tools Used
- Python
- Visual Studio Code

## How It Works
The script scans a selected directory and organizes files based on predefined rules such as file names, categories, or structure. Files are automatically moved into their appropriate folders.

## Purpose
This project demonstrates automation, data organization, and workflow optimization skills. These are essential in data analytics, business operations, and healthcare IT environments where accuracy and efficiency are critical.
