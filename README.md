# AI File Automation Agent

## Overview
This project is a Python-based automation tool designed to organize files and streamline workflow categorization. It automatically routes files into structured folders based on predefined rules, reducing manual effort and improving operational efficiency.

## Features
- Automatically sorts files into categories such as School, Trading, Business, and Books/PDFs
- Applies rule-based logic to determine file placement
- Improves file organization and reduces manual workload
- Supports consistent and repeatable workflow structure

## Tools Used
- Python
- Visual Studio Code

## How It Works
The script scans a selected directory and evaluates files based on predefined rules such as naming patterns or categories. Files are then automatically moved into their appropriate folders, creating a structured and organized system.

## Business Impact
This automation reduces time spent on manual file sorting and improves overall workflow efficiency. Similar logic can be applied to data processing, revenue cycle workflows, and healthcare information systems where accuracy and organization are critical.

## Purpose
This project demonstrates practical skills in automation, data organization, and workflow optimization—key competencies for roles in data analytics, business operations, and healthcare IT.
